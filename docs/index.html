載せられるカードのジャンル

カード自体は、女性の個人活動者の幅広い職種で作れます。ただし、この掲示板の各板に表示されるのは、決めた範囲（健全ジャンル〜メディア系〜フリーセラピストが上限）のカードだけです。範囲外の職種のカードは、カードサイトに存在しても掲示板には出ません。

カードって何？

カードは、掲示板とは独立した別のサイト「プロフィールカード」で作ります。
職種を選んでURLを貼るだけで、自分の公開プロフィールページができます。
